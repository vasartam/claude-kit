# AGENTS.md — репозиторий claude-kit

Личный набор владельца для Claude Code, разложенный по слоям: корень — общий слой, `terminal/`,
`desktop/`, `macos/`, `windows/` — слои оболочки и ОС. Язык — русский. Устройство и подключение —
`README.md`.

## Куда класть

- Верно на любой машине и в любой оболочке — в корень; специфика оболочки или ОС — в каталог её
  слоя; частность одного проекта — в его `docs/`, не сюда; рабочее и личное-не-общее — в
  репозитории из правил машины (`knowledge/tooling-repos.md`).
- Жёсткое правило на каждую сессию — строкой в `USER-CLAUDE.md` слоя; подробности и «почему» — в
  `knowledge/` того же слоя.
- Знание — `<слой>/knowledge/<тема>.md` + строка в индексе этого слоя: `knowledge/README.md` корня или
  `<слой>/knowledge/README.md`. Новый слой — свой индекс и строка в разделе «Знания слоёв» корневого.
- Навык — `<слой>/skills/<имя>/SKILL.md`, имя голое, без префикса; утилита — `<слой>/bin/`, команда —
  `<слой>/commands/`, хук — скрипт в `<слой>/hooks/` и запись в его `hooks.json`, мод —
  `<слой>/mods/<имя>/` с `.claude-plugin/plugin.json` (имя для `exclude` — каталог). Хук или мод,
  которому оболочка не важна, — в общий слой (как `context-guard`, `session-state`); слою оболочки —
  только то, что без неё не работает. Заметно — строкой в дерево `README.md`. Новые навык, утилита,
  команда, хук, мод видны после `python3 scripts/link.py`.

## Размеры

- `USER-CLAUDE.md` грузится в каждую сессию: корневой ≤ ~4 КБ, слоя ≤ ~3 КБ; одна строка на правило,
  подробности — в `knowledge/`.
- `SKILL.md` ≤ 8 КБ (грузится целиком при каждом вызове); подробности и примеры — в `references/`, со
  ссылкой из `SKILL.md` и пояснением, когда читать.
- `knowledge/`: одна тема — один файл ≤ 8 КБ, вырос — делить. Правило — с причиной («почему») и
  случаем, где оно родилось. Индекс `knowledge/README.md` слоя — тоже ≤ 8 КБ: строка на файл, только
  ключевые слова и «когда читать», подробности — в самом файле.
- Одно знание — в одном месте, в остальных — ссылка.

## Переносимость

- Путь набора в текстах — `<kit>` (модель видит его в «Contents of …/USER-CLAUDE.md»), домашний
  каталог — `~`; никаких `/Users/<имя>`, `C:/Users/<имя>`.
- `terminal/` — только переносимое (macOS и Linux). BSD-флаги (`sed -i ''`, `date -j`, `stat -f`),
  osascript, launchd, pbcopy, Keychain, iTerm — в `macos/`. Утилиты зовут друг друга как
  `~/.claude/bin/<имя>`, herdr и jq — из PATH.
- Хуки — `hooks/hooks.json` слоя в штатном формате плагина (`${CLAUDE_PLUGIN_ROOT}` — каталог слоя,
  первое слово `python3`, `node` или `bash`); Python — 3.9+, Node — 18+ (`.mjs`, ESM), без зависимостей,
  только встроенные модули. Имя для `exclude` — имя скрипта без расширения. Модель,
  контекст и лимиты хук берёт у `hooks/session_state.py` (на Node — `hooks/session-state.mjs`, правка —
  в обе версии, пока есть хуки на Python), общие файлы пишет его `write_json`: хуки одного события идут
  параллельно.
- Хук и мод — ссылки на файлы набора: правка действует во всех сессиях машины сразу. Новая настройка —
  сначала значение в конфиге машины, потом код, иначе поведение сменится посреди работы (12.10.2026:
  подпись времени на минуту стала «UTC+3», пока ключа `clock` не было).
- После правки `scripts/link.py` или хуков — тесты: `python3 scripts/test_link.py`,
  `for t in hooks/test_*.py; do python3 "$t"; done`, `node --test hooks/test_*.mjs`,
  `CONTEXT_GUARD_IMPL=node python3 hooks/test_context_guard.py`; тест хука — `hooks/test_<имя>.py`
  или `.mjs`. Мод — `claude plugin test` на копии его каталога (`mods/session-state/README.md`).

## Git

- Перед правкой `git pull --rebase`, после — сразу коммит и push (на Windows — из WSL,
  `windows/USER-CLAUDE.md`). Коммиты маленькие, в сообщении — проект-источник (`… (из <проект>)`).
  Незакоммиченное не оставлять: каталог общий для всех сессий машины.
- Устаревшее не стирать молча: заменить и одной строкой сказать, что и почему изменилось. Смена
  устройства набора (слои, подключение, переезд файлов) — строкой в `CHANGELOG.md`.

## Чистота: набор публичный

- Не писать: секреты, токены, IP серверов, персональные данные третьих лиц.
- Ничего о самом владельце: имя, аккаунты, почта, машины, личные проекты и их адреса, его словечки
  (слово прощания). Это — его личный слой (`knowledge/tooling-repos.md`); в наборе — «владелец», «личный проект»,
  настройка вместо зашитого значения (как `clock` в `hooks/README.md`).
- Ничего с работы владельца: компания и её сервисы, адреса, чаты, ключи задач, имена коллег, рабочие
  репозитории, навыки и пути. Пример из рабочего случая — заменить нейтральным. Рабочие правила
  живут в рабочих настройках машины, не здесь.
- Перед коммитом — `grep -rnE '/Users/|/home/|C:/Users|C:\\Users'` по изменённому.
