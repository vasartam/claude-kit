# context-compact — мод: сжатие без панели herdr

Где нет панели herdr (вкладка Code приложения, терминал вне herdr), сжать контекст после раскладки знаний
мог только владелец, набрав `/compact`. Владелец хочет ничего не делать и ждать, пока сожмёт автоматика
(04.10.2026), — мод делает то же, что `claude-compact` в herdr. Проверен в приложении на Windows
(04.10.2026): сжатие и продолжение пришли без владельца.

1. Хук `hooks/context-guard.mjs` видит файл-признак мода и вместо просьбы владельцу говорит модели: после
   раскладки выполнить отдельной командой Bash `echo "context-compact [--resend <файл>] -- <инструкция>"`.
2. Мод замечает эту команду (`tool.call`, основная сессия; читается сама команда, не вывод `echo`).
3. После конца хода (`turn.complete`, `reason: 'answer'`, пауза 1,5 с — во время хода сжатие движок
   отклоняет) — `$.command.run({ command: 'compact', args: <инструкция> })`: `/compact` как набранный
   владельцем. `$.session.compact` в приложении недоступен (headless), `$.prompt.submit` с «/» не принимает
   (пробы 1–3, `knowledge/claude-code-mods.md`).
4. Сжатие прошло (событие `session.compact` без `skip`) — `$.prompt.submit`: запрос, пришедший до сжатия
   (`--resend`: однострочный — в тексте, иначе — ссылкой на файл), или «продолжи по инструкции». Отменил
   хук `PreCompact` (раскладка не свежая) — ничего: context-guard сам попросит разложить.

- Признак — `<claude>/context-guard/<sid>.compact-mod` (`ok: true` на `session.start`; ошибка
  `$.command.run` или `$.prompt.submit` — `ok: false` и `error`, тогда context-guard снова просит
  владельца). `<claude>` — `CLAUDE_CONFIG_DIR`, иначе `USERPROFILE` или `HOME` + `/.claude`.
- Не трогает сабагентов, прерванный ход и сессии без человека (`CLAUDE_CODE_ENTRYPOINT` `sdk-*`).
- Весь сигнал — в двойных кавычках, внутри без `"`, `$`, `` ` ``: мод читает всю команду, но `;` и `&&`
  без кавычек режут её для оболочки, echo падает, и модель повторяет сигнал (04.10.2026).
- В панели herdr сигнала нет — там ведёт `claude-compact`. Выключить — `exclude: ["context-compact"]`.

## Тесты

`cp -R mods/context-compact /tmp/m && claude plugin test /tmp/m` (на копии: движок кладёт в мод
`types/` и `tsconfig.json`). Разбор сигнала и текст продолжения — `hooks/signal.ts`.
