# msk-time — мод: время ответа ставит программа

Мод дописывает `_04.10.2026 00:30 МСК_` в конец последнего ответа хода — прямо в потоке ответа
(`turn.step`): что выходит из хука, то и показывается, и записывается в транскрипт, в терминале и в
приложении. Модель время больше не пишет. *Почему:* модель досчитывала его «на глаз» от последней заметки
хука и писала будущее; Stop-хук `msk_time` ловил это уже после того, как владелец увидел ответ
(04.10.2026, не раз). Решение владельца — время ставит код, не модель.

Каталог мода вписывает `scripts/link.py` в `env.CLAUDE_CODE_PLUGIN_DIRS`; мод грузится при старте
сессии. Выключить — `exclude: ["msk-time"]`: метку снова пишет модель по заметкам `hooks/msk_time.py`.

## Как устроен

- `turn.step` основной сессии: последний текстовый блок ответа держится «открытым» — служебные куски
  движка после него (конец блока) придерживаются до следующего куска. Пришёл `stop` с `end_turn` — метка
  `\n\n_<время>_` дописывается в тот же блок, затем придержанное и `stop`. Вызов инструмента или
  размышление после текста — текст не последний, метки нет.
- Метку модели мод заменяет своей: конец текста, похожий на `_ДД.ММ.ГГГГ ЧЧ:ММ МСК_` (целиком или
  начало), придерживается до конца хода; оказался меткой — выбрасывается. *Почему:* модель видит метки
  мода в прошлых ответах и подражает им — 04.10.2026 после сжатия вышли две метки подряд.
- Без метки: слово прощания `clock.farewell` (конец сессии), сабагенты, сессии без человека
  (`CLAUDE_CODE_ENTRYPOINT` `sdk-*`: `claude -p`, Agent SDK — их вывод читают скрипты).
- `session.start` — файл-признак `<claude>/msk-time/<sid>.mod` с `ok: true`: хук `hooks/msk_time.py`
  тогда говорит модели «метку не пиши» и в Stop её не требует; нет файла или `ok: false` — прежняя
  схема (метка от модели по заметке «Сейчас …»). `<claude>` — `CLAUDE_CONFIG_DIR`, иначе `USERPROFILE`
  или `HOME` + `/.claude`; `<sid>` — как в `session_state.py`.
- Служебная строка `$.session.append({ message: { type: 'system' } })` не подошла: в транскрипт она
  ложится, но терминал её не рисует (проба 04.10.2026).

## Тесты

`claude plugin test` на копии каталога (движок кладёт в мод `types/` и `tsconfig.json`):
`cp -R mods/msk-time /tmp/m && claude plugin test /tmp/m`. Пути в тестах сравниваются без диска и
обратных слэшей: на Windows движок отдаёт `C:\home\u\…`.
