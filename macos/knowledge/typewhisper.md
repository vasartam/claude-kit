# Голосовой ввод на Mac: TypeWhisper

Общее про голос владельца (термины искажаются — восстанавливать по смыслу, словарь) — в
`knowledge/owner.md` общего слоя. Здесь — локальная диктовка TypeWhisper.

TypeWhisper (`brew install --cask typewhisper`) поставлен 2026-09-04 как обход того, что встроенный
голосовой ввод Claude Code в терминале умирает после автообновления (`voice.md`): у TypeWhisper свой
процесс на каждую запись, обновление claude ему не вредит. Но и он глохнет сам — см. грабли.

## Рабочая конфигурация

- Движок `whisper` (плагин WhisperKit из Integrations), модель `openai_whisper-large-v3`, для
  скорости — `large-v3_turbo`.
- Лёгкий «Live preview engine» (`whisper-small`) и «Show live transcript in the active text field».
- Разрешение **Универсальный доступ** — без него вставка в поле не работает вообще.
- Языки — полный автоопределитель; «restrict detection to selected languages» выключить.

## Грабли (каждая стоила времени)

- У Apple SpeechAnalyzer **русской модели нет** (30 локалей, `ru` нет) — русский на нём не заработает.
- Parakeet — под английский и зависает в состоянии transcribing до перезапуска приложения.
- Движки без подсказок берут **первый язык списка как жёсткий**: при `["ru","en"]` английская речь
  пишется по-русски.
- **Термины словаря (Dictionary → Terms) вредят локальному Whisper:** уходят в модель затравкой,
  видны в живом транскрипте и замедляют распознавание (документация: «Terms improve *cloud*
  recognition»). Terms держать пустыми, пользоваться автозаменами (Corrections) — они применяются
  после распознавания и на скорость не влияют.
- **Живое превью слов по ходу речи недостижимо** (проверено 2026-09-04): возможность
  `live-transcript` не объявляет ни один плагин каталога, окно пустое до конца записи при любых
  `livePreview*`. Поток с русским есть только у облачных движков (Sber SaluteSpeech, Deepgram,
  Soniox, Speechmatics) — они отдают звук наружу. Повторно на это время не тратить.
- **Авто-Enter после вставки** живёт в правиле workflow (Settings → Workflows, только GUI), а не
  глобально: ключ `autoEnterEnabled` сам не срабатывает. Целевое приложение — хост терминала
  (iTerm, `com.googlecode.iterm2`), не мультиплексор (`iterm.md`); в мессенджерах автоотправка не
  нужна — владелец сказал явно.
- **Глохнет через несколько суток работы:** «no speech recognized» при плоской полоске уровня, хотя
  бандл не менялся (2026-09-07, через трое суток после запуска). Лечит только перезапуск
  приложения; причина не найдена, с обновлением Claude Code (`voice.md`) не связана. Гипотеза (не
  проверена): клиент с закэшированным форматом глохнет при смене конфигурации аудиоустройств (число
  устройств 4 → 3, прыжки частоты). При следующей поломке сверить её время со сменами устройств.
- `defaults write` переживает перезапуск, но имена ключей восстановлены из строк бинарника —
  совпадение не гарантировано. Надёжнее GUI; для сравнения — снимок `defaults read` до и после.

## Локальный API

- Settings → Advanced → «Enable API server»: порт 8978, только localhost; токен и порт — в
  `~/Library/Application Support/TypeWhisper/api-discovery.json` (поля `token`, `port`).
- Версия 1.1: `/v1/status`, `/v1/models` (только список), `/v1/dictionary/terms`,
  `/v1/dictionary/corrections` (`PUT {"original": …, "replacement": …, "caseSensitive": false}`),
  `/v1/dictation/start`, **`POST /v1/transcribe`** (в README нет, найден 2026-09-25). Моделями —
  только через GUI: `/v1/models/load` из README в этой версии нет.
- Автозамены машины заливать своим скриптом через этот API и пополнять там же.

## Расшифровка записи — только кусками

Аудио Claude не принимает (на входе текст, картинки, PDF), а облачные распознаватели отдают звук
наружу — поэтому распознаёт локальный Whisper через API, анализирует Claude по тексту.

```bash
T=$(python3 -c 'import json,os;print(json.load(open(os.path.expanduser("~/Library/Application Support/TypeWhisper/api-discovery.json")))["token"])')
ffmpeg -i in.m4a -ar 16000 -ac 1 rec.wav
mkdir -p ch && ffmpeg -i rec.wav -f segment -segment_time 45 ch/c%02d.wav   # резать обязательно
for f in ch/c*.wav; do curl -s -X POST http://127.0.0.1:8978/v1/transcribe \
  -H "Authorization: Bearer $T" -F "file=@$f" -F language=ru; done          # JSON, поле text
```

Одним файлом (8,5 мин) Whisper выкинул больше половины речи и зациклился на повторе фразы;
кусками по 45 с распознал почти всё. Скорость large-v3 — около 70 с на 8,5 мин записи. Голоса он не
различает — кто что сказал, восстанавливать по смыслу и помечать как догадку.
