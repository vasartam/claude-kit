# Утренняя газета

Сверстанный отчёт-страница после ночной (или любой большой) работы без владельца: он читает её
утром как газету — с телефона и компьютера. Делается **сама, без напоминаний**, в конце такой
работы; по словам «утренняя газета», «сверстанный отчёт», «отчёт с графиками» — и вне ночи.

## Сначала отчёт

Источник истины — markdown-отчёт в репозитории по [шаблону](references/report-template.md):
`docs/reports/<ГГГГ-ММ-ДД>-night.md` для ночи, иначе `docs/reports/<ГГГГ-ММ-ДД>-<тема>.md`; нет
репозитория — рядом с заметками работы. Черновик ведётся с первого шага и дописывается перед
каждой паузой — отчёт есть в любом случае. Газета — его вёрстка.

## Газета

- **Перед вёрсткой** загрузить навыки `artifact-design` и `dataviz` и следовать им.
- **Образцы стиля:** образец в личном слое владельца, если подключён (индекс его знаний), и опубликованные
  страницы владельца (`Artifact` list → read).
- **Состав:** шапка (дата, проект); итог в трёх строках; плитки-цифры (часы работы, коммиты,
  выкладки, тесты было → стало, пик лимита, происшествия); график лимита за ночь с паузами и
  сбросами; хронология (свёрнутые детали по этапам); разделы по задачам с «как посмотреть»;
  честные «Происшествия»; крупный блок «Ждёт вас» с готовыми командами; «Что дальше».
- **Данные** для графиков — из журнала работы (поэтому журнал ведётся с цифрами: время,
  проценты лимита, что сделано) и из git (коммиты, выкладки, число тестов).
- **Публикация:** `Artifact` (страница приватная), ссылка — в чат и в журнал работы.
- Несколько сессий работали одновременно (night-work) — координатор делает ещё и **общую
  газету**: главную страницу утра со ссылками на газеты сессий.
