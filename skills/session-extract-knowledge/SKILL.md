# Разложить знания по местам

Цель: после сжатия и в новой сессии ничего ценного не потеряно. Когда раскладывать —
`<kit>/knowledge/session-hygiene.md`. Здесь — единственное описание **порядка**; `session-end`
выполняет его же. Результат — **записи в файлах**, а не пересказ: нет ни одной записи —
порядок не выполнен. Без разрешения на каждую запись.

## Кто зовёт

| Кто | Материал | Концовка |
|---|---|---|
| владелец: «разложи», «вынеси знания», /compact | сессия | отчёт списком, затем сжать |
| владелец: «извлеки знания из …», «разбери …» | источник | отчёт списком, не сжимать |
| хук контроля контекста или лимита подписки | сессия | как сказано в сообщении хука |
| перезапуск сессии | сессия | строкой «готово»; не сжимать, не прощаться |
| навык `session-end` | сессия | ничего своего, ведёт он |

Как сжать и кто ещё зовёт в этой оболочке — «Сжатие и закрытие сессии» в правилах слоя.

Сессия — только новое после прошлых сжатия и раскладки. Внешний источник — открывать ссылки
внутри: суть за ссылкой, и дата документа там важнее даты публикации. Нет доступа — назвать
ссылку и причину, в обход не пересказывать.

## Режим

- **Полный** — просьба владельца, перед сжатием, из `session-end`.
- **Короткий** — хук отложил автосжатие, мало места: только незаписанное, одной-двумя
  правками, без чтения больших файлов.

## Шаги

1. **Кандидаты** — факты об окружении, инструментах, репозиториях; правила владельца и
   поправки мне; ошибки — причина, механизм, обход; починки — числами «до/после»; статус и
   хвосты; приёмы и команды на будущее. Техническое — раньше продуктового.
2. **Дубли.** `git status`/`git log` сессии в проекте и в наборе; `rg -l -i --hidden
   --no-ignore` (без флагов — ложное «записи нет») и индексы (`knowledge/README.md`,
   `MEMORY.md`). Запись есть — обновить, неверную — исправить, не копить рядом. Нового нет —
   «уже разложено», шаги 3–6 пропустить.
3. **Место** — таблица ниже. Одно знание — одно место, в остальных — ссылка.
4. **Конфликт с записанным** — по датам (`git log -1 --format=%ad -S'<фрагмент>' -- <файл>`
   или `modified` во frontmatter): материал заметно новее — обновить; запись новее —
   пропустить; разница мала или противоречие принципиальное — **не менять**, вынести
   владельцу обе формулировки с датами.
5. **Записать** — коротко, в стиле файла; правило — с причиной и датой. Коммит и push сразу
   (набор — по его `USER-CLAUDE.md`).
6. **Правки инструкций.** Не новый факт, а сбой в моём подходе — найти правило или навык,
   откуда он: что случилось → урок → файл → правка, по одной. Прямую поправку владельца —
   сразу; своё обобщение шире сказанного — предложить.
7. **Отметка** — отдельной командой Bash `echo knowledge-sorted` (для хука context-guard; в
   herdr — до `claude-compact`).
8. **Концовка** — ниже.

## Куда писать

**Раздел «Раскладка знаний» в правилах машины (`CLAUDE.md`, слой, память) главнее.** Иначе —
сначала репозиторий (`<kit>/knowledge/tooling-repos.md`), затем место:

| Что | Куда |
|---|---|
| Рабочее (компания, коллеги, её репозитории) | рабочий репозиторий или память машины; их нет — не записывать, сказать владельцу |
| Проект: решения, замеры, баги, статус | `docs/` проекта по его `AGENTS.md` |
| Личное, не общее | личный репозиторий машины; нет — спросить, в набор не класть |
| Общее (любая машина, вне работы) | набор, слой по его `AGENTS.md`: правило каждого ответа — строкой в `USER-CLAUDE.md`; знание — `knowledge/<тема>.md` + строка в индексе; метод — `dev-method`; поведение навыка, хука — его `SKILL.md` / README |
| Мелочь одной папки (не в git) | память проекта Claude Code (`~/.claude/projects/<папка>/memory/`) |

Большая память деревом — [references/memory-layout.md](references/memory-layout.md).

**Не записывать:** секреты — никогда; эфемерное одной задачи; видное из кода и git. **При
сомнении не записывать:** ошибочно внесённое хуже невнесённого.

## Концовка

Сначала — решаемое только владельцем: конфликт из шага 4, разрушающий шаг, упавший push.
Есть — спросить и дальше не идти: ни сжатия, ни закрытия.

Иначе — по таблице «Кто зовёт»: отчёт — что и куда записано, что осознанно нет (хуку —
строкой); сжатие — способом оболочки. Хук отложил автосжатие — строкой «что куда легло» и
вернуться к работе. Задаче нужен весь контекст — отложить цитатой «> контекст Nk, проверка
отложена до Mk: <зачем>» последней строкой ответа (хук context-guard, в любой оболочке); подробно —
`<kit>/hooks/README.md`.
