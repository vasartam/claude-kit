# Универсальный минимум классов дефектов

Открывать, когда в проекте нет своего каталога. Есть каталог (например, `docs/ui-pitfalls.md`)
— читать его: там те же классы, но с конкретикой проекта и рецептами на его стеке.

Список собран по разбору одного реального экрана-таблицы: двенадцать итераций ручной
проверки, каждая закончилась правкой кода.

| Класс | Что проверять всегда |
|---|---|
| Объём данных | Пусто, одна строка, короткий список, полная страница, больше страницы. Любое `min-height` и любое растяжение проверяется на списке из одной строки |
| Пропавшие соседи | Пагинация, счётчики, фильтры исчезают вместе с данными — соседние элементы не должны сдвигаться |
| Форма ↔ адрес ↔ запрос | Набранное не исчезает через задержку; адресом можно поделиться; из адреса восстанавливается; смена фильтра сбрасывает страницу |
| Семантика параметров | Каждое поле уходит параметром, который бэкенд понимает так же, как пользователь: точное сравнение, подстрока, И или ИЛИ |
| Три исхода правки | Сохранить, отменить, отвергнуть. Отвергнутая правка откатывается к сохранённому и не тянет соседние поля |
| Ререндер | Ввод не перерисовывает соседние строки; фоновое обновление не гасит и не мигает |
| Валидация | Крайние значения, пробелы, буквы в числовых полях, большие числа, дубли, ноль как значащее значение |
| Файлы | Кодировка и BOM, разделитель локали, кавычки, перевод строки внутри поля, колонки по заголовку; круг «выгрузил — поправил — загрузил» не удваивает записи |
| Отклик | Массовое действие отчитывается о результате; частичный успех отличается от полного; ошибка видна там, где действие |
| Аффордансы | Курсор-указатель только там, где клик что-то делает; мёртвые CSS-модули не влияют ни на что |
| Выравнивание | Элементы управления и заголовки шапки стоят ровно над содержимым своих колонок; подсказки в полях открытой ячейки не обрезаны. Сдвиг в 6–8px на снимке всего экрана не виден — только замером или увеличенным снимком |

## Приёмы (Playwright)

| Приём | Чем ловит |
|---|---|
| `boundingBox()` до и после действия | Высоты строк, ширины колонок, уехавшие элементы |
| `getComputedStyle` через `evaluate` | Курсоры, прозрачность, видимость — без завязки на хеши CSS-модулей |
| Атрибут-метка через `evaluate` | Пересоздание узлов: метка переживает ререндер и не переживает пересоздание |
| `waitForRequest` + `postDataJSON()` | Что реально ушло на бэкенд, вместо ассерта на снекбар |
| Мок с состоянием в замыкании | Что экран действительно сохранил; круг «выгрузил — загрузил» |
| Задержка перед ответом мока | Мигание, оверлеи, подмена данных в момент обновления |
| Левые края видимых узлов колонки (`getBoundingClientRect` значка и текста, не обёртки) | Шапка и строки разъехались на несколько пикселей |
| Снимок состояния в артефакты | Всё, что описывается словами «выглядит криво» |
| Подписка на `console` | Ошибки и предупреждения фреймворка, которых не видно в ассертах |
