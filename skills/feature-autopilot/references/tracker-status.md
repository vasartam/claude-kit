# Статус задачи в трекере за шагами конвейера

Читать при каждом переходе фазы автопилота (`../SKILL.md`).

**Статус задачи в трекере идёт за шагами конвейера** — переводить в том же ходу, где сделан шаг,
не дожидаясь просьбы:

| Шаг | Статус |
|---|---|
| Взялся за задачу | «в работе» (In Progress) |
| Все MR задачи ушли на ревью | «на ревью» (In Review) |
| Все MR одобрены и ждут раскатки | «исправлено» (Fixed) |
| Изменение проверено на проде и включено: флаг раскатан на всех или эксперимент запущен (если задача раскатывается так) | «закрыта» (Closed) |

Пока шаг не пройден всеми MR задачи, статус не двигать: один MR на ревью при другом в работе —
ещё «в работе». Названия статусов — по процессу проекта (переходы трекера). После каждого перевода
сверить статус — автоматике трекера не доверять. Код на проде под выключенным флагом — ещё «исправлено», не
«закрыта». Колонки, которые процесс отводит другой роли (например, тестировщикам), не трогать.
