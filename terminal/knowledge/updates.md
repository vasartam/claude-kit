# Обновления Claude Code и живые панели

Перезапуск на месте — [restart-in-place.md](restart-in-place.md).

## Старая версия в живых панелях

Живая панель крутит версию, с которой стартовала, сколько бы раз Claude Code ни обновился: «работает
в новой вкладке, не в старой» — сначала сверить время старта процесса (`ps -Ao pid,ppid,lstart,command
| grep '[c]laude'`) с журналом обновления `~/.claude/.last-update-result.json` (`version_from`,
`version_to`, время), а не искать причину в правах. `claude --version` показывает версию на диске, а
не процесса. Лечится перезапуском на месте (`--resume <session_id>`).

- Нативный установщик: `~/.local/bin/claude` → `~/.local/share/claude/versions/<ver>`, обновление
  кладёт версию рядом и старый файл не трогает, пока им пользуются; версия процесса — в его имени
  (`2.1.282`) и в пути `lsof -d txt`, у npm-установки имя — `claude.exe`.
- Старая npm-копия в PATH (например, в версии node, которую включает `.nvmrc` проекта через nvm)
  находится раньше нативной и сама обновляется через npm. Признак — `installMethod` в `~/.claude.json`
  сменился с `native` на `global`. Слишком старая копия не знает новых моделей
  (`claude_code_version_too_old`) и стартует на модели аккаунта по умолчанию (01.10.2026).
- Новую сессию, которую заводишь сам через `herdr agent start`, проверить: `herdr agent read <имя>` —
  версия и модель должны совпадать с твоими. Модель задавать явно `-- --model <id>`: в `settings.json`
  её нет, и новая сессия возьмёт модель аккаунта по умолчанию. Версия не та — перезапустить с
  `--resume`.

## Голосовой ввод умер во всех старых панелях

Симптом: «No audio detected…» сразу во всех открытых панелях, свежая панель работает. Причина —
обновление удалило файл программы у живых процессов (npm-установка); механизм на macOS (TCC) —
`<kit>/macos/knowledge/voice.md`. Лечение — только перезапуск процесса: `claude-restart` в панели или
`--stale` для всех панелей с удалённым файлом. Перезапуск herdr — не отдельное решение: он убьёт
все панели разом. Корень — нативный установщик (файлы живых версий не удаляет). Профилактика —
`autoUpdates: false` в `~/.claude/settings.json` или `DISABLE_AUTOUPDATER=1` и ручные обновления с
перезапуском панелей; при нативной установке ключ `autoUpdates: false` автообновление **не**
выключает (`autoUpdatesProtectedForNative`).
