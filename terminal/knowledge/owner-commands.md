# Команды владельца через `!`

`! <команда>` в поле ввода Claude Code выполняет команду от имени владельца, вывод уходит в контекст
сессии. Правило слоя: команду для владельца давать одной строкой `! …`.

- **Классификатор auto mode `!`-команды не проверяет.** Так владелец запускает то, что агенту
  запрещено: правку своих прав, `automode-add-rule` (`<kit>/knowledge/claude-code-permissions.md`).
- **Короткая команда одной строкой**, длинный текст — заранее в файл: длинные `!`-команды бьются при
  вставке (30.09.2026 из heredoc-патча выпали куски, и файл сломался). Длинное — сначала проверить
  (`python3 -m py_compile`, `bash -n`), откат — `git checkout -- <файл>`.
- **`!`, как и инструмент Bash, идёт без TTY** (`<kit>/knowledge/claude-code.md`): интерактивный
  конфигуратор падает на первом вопросе, интерактивный `claude` уходит в `--print` и падает
  («Input must be provided either through stdin or as a prompt argument», 30.09.2026).
- Интерактивное и секреты — в чистой вкладке шелла (herdr: `Ctrl+B`, `C`), не во вкладке с идущим
  Claude: всё набранное в панели агента попадает в его контекст (как ещё — там же, в `claude-code.md`).
