# Слой terminal: Claude Code в терминале и herdr

Панель herdr (`HERDR_PANE_ID`); утилиты — `~/.claude/bin/`, знания — `<kit>/terminal/knowledge/`.

- Команду для владельца — одной строкой `! …`, длинное — заранее в файл, интерактивное (пароль, TTY) — в отдельной вкладке (`owner-commands.md`).
- Метку вкладки herdr менять **только при смене основной задачи** (5 промптов подряд о новой или прежняя закрыта; побочная не в счёт), сразу — метку-заглушку (ID/слаг/`claude`): `herdr tab rename "$HERDR_TAB_ID" "<3–7 слов по-русски>"`, в ответе строка `🏷️ Вкладка: «было» → «стало»` (`herdr-naming.md`); текущая — в строке хука `model-advisor`.

## Совет по модели

Общее правило — `<kit>/knowledge/model-advice.md`; переключать здесь — `/model`, `/effort <уровень>`, `/effort ultracode on|off`.
- Совет и ожидание решает хук: `wait:` в его строке — к задаче не приступать, 2–3 строки по его «Совет (…): …», «продолжай» — на текущих, без ответа продолжу сам; последним действием — команда из `wait:` (таймаут — согласие на модель, не на «покажи перед отправкой»). Ход от уведомления (фоновая задача, сабагент) во время ожидания `claude-autocontinue` считает ответом владельца — в его конце снова команда из `wait:`.
- Нет `wait:` — не ждать и работать.

## Сжатие и закрытие сессии

- Контекст стережёт хук `context-guard` общего слоя (`<kit>/hooks/README.md`); в панели herdr сжатие после раскладки ведут он и `claude-compact`.
- Сжать (после раскладки): подробности — в `~/.claude/context-guard/<session_id>.after-compact.md`, затем `~/.claude/bin/claude-compact -- <инструкция ≤250 символов, одна строка>`, конец хода.
- Закрыть (/session-end): `~/.claude/bin/claude-close` последним действием, затем слово прощания (`answer-style.md`).
- Вне herdr (`HERDR_PANE_ID` пуст) сжимает мод: `echo "context-compact -- <инструкция>"` (в кавычках; как скажет context-guard); без мода — попросить владельца `/compact <инструкция>`; закрыть — `/exit`.
- Подробности — `session-compact.md`; перезапуск на месте — `/restart-session`.
