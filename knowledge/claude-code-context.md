# Claude Code: контекст, транскрипт, стоимость

## Заполнение и сжатие

- Заполнение контекста — по записи сессии `~/.claude/projects/<папка>/<session_id>.jsonl`:
  `message.usage` последнего ответа (`input` + `cache_creation` + `cache_read` + `output`).
  Граница сжатия — строка `"subtype":"compact_boundary"` с `preTokens`/`postTokens`
  (`compactMetadata`); сразу после сжатия новых ответов в записи ещё нет. Запись после сжатия
  цела. Записи хранятся около месяца.
- Окно модели — из каталога моделей Claude Code; для имени не на `claude-` (сторонний провайдер)
  по умолчанию 200k, и в баннере «context assumed to be 200k tokens». Переопределяется
  `CLAUDE_CODE_MAX_CONTEXT_TOKENS=<токены>` — по коду бинарника сначала окно самой модели,
  потом эта переменная (только для имён не на `claude-`), иначе 200k.
  `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT` снимает само предупреждение, но размер
  окна не задаёт. Переменной `CLAUDE_CODE_CONTEXT_LIMIT` в Claude Code нет — её молча игнорируют,
  поэтому лимит, выставленный провайдером прокси, на окно не влияет.
- Автосжатие при окне 1M — на ~967K (замер `preTokens` 967 567). Порог задаёт
  `CLAUDE_CODE_AUTO_COMPACT_WINDOW=<токены>` (или `autoCompactWindow` в настройках) — им же можно
  вызвать автосжатие на маленьком контексте для опыта; `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=40` на
  Haiku автосжатие не вызвал.

## Что есть в транскрипте

- У записей `type:"assistant"` — поля верхнего уровня `effort` и `perTurnEffort` (2.1.288);
  вложение `attachment.type:"model"` (`identity.modelId`); `entrypoint` (`cli` — терминал).
- **Ultracode не передаётся никуда, кроме транскрипта.** Ответ `/effort`
  (`<local-command-stdout>Ultracode on…` / `Ultracode off.`) пишется сразу; вложения
  `ultra_effort_enter`/`ultra_effort_exit` — только со следующим настоящим промптом (сообщение,
  поставленное в очередь посреди хода, не в счёт). Переключение клавишей Tab в пикере `/effort`
  не оставляет ничего, кроме `ultra_effort_enter` со следующим промптом, — до него источника нет
  нигде (03.10.2026). Выбор effort пишется в `settings.json`, ultracode — нет. Случай «выключил, а
  показывает включённым» разбирать grep'ом по транскрипту именно этой сессии.
- **Сабагент**: `<запись сессии без .jsonl>/subagents/agent-<id>.jsonl` с `message.model` и
  `message.usage`, рядом `agent-<id>.meta.json` (тип, описание, запрошенная модель). Effort в
  транскрипте сабагента нет.
- Grep по транскрипту со скриншотом (base64 — мегабайтная строка) без `-o` висит минутами:
  искать `grep -a -o` с короткими шаблонами или `jq -c` построчно.

## Сколько стоит контекст

Замеры 30.09.2026, CLI 2.1.284, первый запрос к модели в записях сессий; машина с ~150
навыками и ~650 инструментами MCP — с меньшим набором старт меньше.

- **Свежая сессия**: Opus 64–75k, Sonnet 55–60k. `/context` в `claude -p` насчитывает ~23k:
  интерактивная сессия добавляет список навыков (10–15k), названия инструментов MCP (описания
  отложены, но названия в контексте всегда, 8–10k), инструкции MCP-серверов, тексты хуков
  `SessionStart`.
- **Сабагент** стартует не с нуля: Haiku ~40k, Opus ~55k (инструменты, `CLAUDE.md`, навыки) и
  каждый раз заново пишет это в кэш. Короткую задачу дешевле сделать самому, длинную механическую
  — отдать дешёвому сабагенту (`subagents.md`).
- **Кэш**: обработанный префикс не пересчитывается, чтение из кэша в API — ~10 % цены ввода (веса
  для лимитов подписки не публикуются). Но контекст перечитывается на каждом шаге (каждом вызове
  инструмента): шаг на 500k стоит примерно как некэшированное чтение 50k. Кэш живёт час. Кэш по
  моделям и цены — `claude-models.md`.
- **Что копится**: текст хука `UserPromptSubmit` идёт с каждым промптом и остаётся до сжатия —
  600 токенов за 100 промптов дали ~60k. Длинные правила — в `CLAUDE.md`, строка хука — ~100
  токенов.
- **Русский** примерно в 1,5–2 раза дороже английского по токенам; перевод `CLAUDE.md` и индексов
  сэкономил бы 2–3k из ~65k — владелец решил не переводить. Выгодно только для текста, который
  повторяется на каждом промпте.
- Отключение 46 неиспользуемых навыков дало ~3,9k: ~6 % старта, ~1,3 % при контексте 300k.
