# Claude in Chrome: данные из вкладки и секреты

Часть `claude-in-chrome.md`: как забирать данные со страницы, не таща секреты через контекст.

- `javascript_tool` возвращает `[BLOCKED: Cookie/query string data]`, если в выводе cookie или
  query-строки, — даже на безобидном (`String(fn)` с URL внутри). Сужать вывод до флагов и
  счётчиков, а не протаскивать содержимое.
- Классификатор auto mode режет JS, читающий `localStorage` или исходники в поисках
  `access_token`, — даже на аккаунте владельца. Обходить не надо: пусть страница сама делает
  авторизованные вызовы и сама отдаёт результат (файлом или ответами пачками) — секрет через
  контекст не идёт.
- `fetch` из https-страницы на `localhost`/`127.0.0.1` не проходит («Failed to fetch»;
  `sendBeacon` возвращает true, но не доходит) — данные из вкладки забирать ответами
  `javascript_tool`, пачками, в компактной кодировке. Таймеры скрытой вкладки Chrome
  «замораживает» — паузы через таймер Web Worker. Вкладка может закрыться — в памяти страницы
  держать небольшую пачку и забирать часто.
