# Claude in Chrome: данные из вкладки и секреты

Часть `claude-in-chrome.md`: как забирать данные со страницы, не таща секреты через контекст.

- `javascript_tool` возвращает `[BLOCKED: Cookie/query string data]`, если в выводе cookie или
  query-строки, — даже на безобидном (`String(fn)` с URL внутри). Сужать вывод до флагов и
  счётчиков, а не протаскивать содержимое. Ещё режет: значение под ключом `author` —
  `[BLOCKED: Sensitive key]` (имя автора сообщения под ключом `who` проходит), строки, похожие на
  base64 (длинные имена классов CSS-модулей, `location.pathname` с base64 внутри) — 27.10.2026.
- Классификатор auto mode режет JS, читающий `localStorage` или исходники в поисках
  `access_token`, — даже на аккаунте владельца. Обходить не надо: пусть страница сама делает
  авторизованные вызовы и сама отдаёт результат (файлом или ответами пачками) — секрет через
  контекст не идёт.
  «Сама» — это её собственные вызовы: перехватить заголовок `Authorization` из её `fetch` и
  повторить им запрос к другому методу API (то, что страница сама не вызывала) классификатор режет
  как `[Unauthorized Access]` (17.11.2026), хотя токен в контекст не попал. Не обходить: читать DOM
  (то, что страница уже показала), а нужное не на экране — открыть её раздел обычным `navigate`.
- `fetch` из https-страницы на `localhost`/`127.0.0.1` не проходит («Failed to fetch»;
  `sendBeacon` возвращает true, но не доходит) — данные из вкладки забирать ответами
  `javascript_tool`, пачками, в компактной кодировке. Таймеры скрытой вкладки Chrome
  «замораживает» — паузы через таймер Web Worker. Вкладка может закрыться — в памяти страницы
  держать небольшую пачку и забирать часто.
- `javascript_tool` в только что созданной группе может отвечать «Debugger is not attached to the tab»
  даже после `navigate` — один вызов `get_page_text` (или `computer`) на этой вкладке подключает
  отладчик, дальше JS работает (18.11.2026). `get_page_text` на SPA, которая не успела
  отрисоваться, даёт «No text content found» — подождать и читать JS-ом `document.body.innerText`.
