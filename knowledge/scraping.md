# Сбор данных с чужих сайтов и API

- **Скорость — замером до запуска**: пробы на нескольких уровнях (например 8/15/25 запросов/с по
  200 запросов: ошибки, 429, задержка), брать с запасом. Квоту без заголовков мерить паузами:
  после 429 — тишина 5, 10 минут, потом по одному запросу. Разные IP — независимые лимиты:
  несколько машин качают непересекающиеся диапазоны, потом слияние.
- Прямой запрос без `Origin`/`Referer` сайта часто получает заглушку; бэкенд бывает на другом
  домене. WebSocket может присылать данные раньше REST — смотреть оба.
- Поля и механика меняются со временем: отмечать, с какого id или даты есть какое поле; факты о
  сайте — с датой проверки.
- API может однажды вернуть объект из чужой нумерации: без фильтра «скачок id больше порога» —
  «дыра» на миллионы id и нехватка памяти. Идентификатор не вычислять, а брать у источника,
  источник значения хранить (`analysis.md`).
- SQLite для сборщика: WAL и автокоммит (иначе параллельные писатели держат длинные транзакции и
  блокируют друг друга); переносить базу только вместе с `-wal`/`-shm` и после остановки
  процессов; бэкап — онлайн `sqlite3.backup`. Слияние частей — `INSERT OR IGNORE`; проверка:
  повторное слияние даёт +0, повторный запуск сборщика ничего не качает.
- `ThreadPoolExecutor.map` на миллион задач создаёт миллион Future — подавать пачками.
- **HAR содержит токены сессии**: разбирать скриптом с маскированием, не коммитить (`*.har` в
  `.gitignore`), не пересылать, после разбора посоветовать владельцу удалить. Вход на сайт —
  владелец; токен, который страница читает из `localStorage`, из браузера не выводить.
- Данные из вкладки со входом владельца — браузер агента (`claude-in-chrome.md`).
- Обход антибот-защиты — не по умолчанию: границы задаёт проект (в аудите игр — запрещён).
- **Чужое API: сначала схема, потом проза.** У документации на Docusaurus с плагином OpenAPI точные
  схемы лежат в `/llms-full.txt` (в HTML схема подгружается скриптом, PDF-таблицы разъезжаются), у
  gRPC-API — `.proto`/`.pyi` в официальном SDK (`pip download` в рабочую папку, не ставить в окружение).
  В прозе и примерах сайтов встречаются ошибки: у Finam Trade API пример на сайте шлёт `Bearer`, а по
  схеме, SDK и официальному клиенту JWT идёт в `Authorization` без префикса (личный проект, 2026-09-26).
