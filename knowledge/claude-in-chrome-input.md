# Claude in Chrome: ввод на странице

Часть `claude-in-chrome.md`: как кликать и вводить текст, чтобы действие дошло до страницы.

- **Координаты кликов плывут, если окно меняло размер**: клики и даже клик по `ref` из `find`
  уходят мимо; баннер над таблицей тоже сдвигает строки — пересчитывать после каждого действия
  (01.10.2026); пропал баннер после удачного сохранения — второй клик пачки мимо, пробел из
  набора листает страницу (12.10.2026): в пачке проверять `activeElement` после клика. Окно может
  растянуть и владелец, наблюдая за работой: клик по координатам снимка, сделанного до этого,
  открыл другой чат из списка (27.10.2026) — кликать только по снимку из того же хода.
- **Нативный `<select>`** рисует ОС: клавиши расширения до него не доходят — нативный сеттер
  `value` + `change` из JS, в отчёте так и сказать. Свой CustomSelect страницы — кликом.
- **Надёжный ввод**: фокус из `javascript_tool` (`el.focus(); el.select()`) → проверить
  `document.activeElement` → только потом `computer type`/`key`; после — проверить значение поля:
  набор без фокуса молча теряется. Кириллица через `type` может терять буквы (2026-10-12: «по слоям» →
  «по слям»): текст в поле — `form_input` по `ref`.
- **JS `el.click()` — не клик мышью**: настоящий клик сначала снимает фокус (`blur` → сохранение
  ячейки), JS-клик — нет, и правка в ячейке таблицы выглядит потерянной. Имитировать:
  `document.activeElement.blur()`, потом `click()`. Выпадающие списки удобно ставить `form_input`
  по `ref`.
- **Многострочный текст в поле мессенджера** (contenteditable, где Enter отправляет, а `@имя`
  открывает подсказку, которую Enter выбирает): не набирать `type`, а вставить событием paste —
  `new DataTransfer()`, `setData('text/plain', текст)`, `dispatchEvent(new ClipboardEvent('paste',
  {clipboardData: dt, bubbles: true, cancelable: true}))` после `focus()`; переносы целы, подсказка
  не всплывает. Затем сверить `innerText` с текстом и нажимать «Отправить» в том же вызове, что и
  сверка, — без зазора между проверкой и отправкой (27.10.2026).
- **Кнопка, видная только при наведении** (действия у сообщения, строки): клик по её `ref` из
  `find` попадает в элемент под ней (выделил сообщение вместо меню) — сначала `hover`, затем снимок
  или `zoom` и клик по координатам с него (27.10.2026).
- Ввод из расширения перестал доходить до страницы — не биться, перенести остаток сценария в
  headless Playwright.
