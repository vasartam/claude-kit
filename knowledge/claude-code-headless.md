# Claude Code без окна: `claude -p`

- **Вложенный `claude -p` получает пустой промпт.** Запущенный изнутри сессии Claude Code, он
  стартует без задачи, отвечает «запроса нет» и выходит **с кодом 0** — проверка `$?` и детекторы
  ошибок отказ не видят, а агент ещё и начинает осматриваться в рабочем каталоге (28.09.2026).
  - Признак вложенности — `CLAUDECODE=1` и `CLAUDE_CODE_SESSION_ID` (есть ещё
    `CLAUDE_CODE_ENTRYPOINT`, `CLAUDE_PID`). Инструмент, зовущий `claude -p`, проверяет их и
    пропускает ИИ-шаг с внятным сообщением — особенно там, где холостой прогон тратит попытку,
    лимит повторов или бюджет.
  - Читать как `${CLAUDECODE:-}`: под `set -u` голое `$CLAUDECODE` роняет скрипт там, где
    переменной нет (под планировщиком), а из сессии этого не видно — переменная там задана.
  - ИИ-шаги проверять боевым путём — запуском через планировщик машины, а не из сессии (macOS —
    `macos/knowledge/`).
- **Детерминированный фоновый прогон**: `claude -p --settings '{"disableAllHooks":true}' --strict-mcp-config
  --mcp-config '{"mcpServers":{}}' …` — хуки погашены, ни один MCP не поднимается. `'{"hooks":{}}'` хуки
  **не** гасит: хуки из `--settings` складываются с хуками `~/.claude/settings.json` (проверено на 2.1.296,
  12.10.2026). Так же добавляют свой хук одному прогону — `--settings '{"hooks":{"PreToolUse":[…]}}'`,
  вход и пользовательские настройки при этом не теряются. Изолировать
  через `CLAUDE_CONFIG_DIR` нельзя: вход лежит в `~/.claude`, в другом каталоге — `Not logged in`.
- **`claude -p` не правит файлы в `~/.claude/**`**: правка — «sensitive file», нужно интерактивное
  подтверждение, а взять его неоткуда. `permissions.allow` не помогает: `Write(...)` в файловых
  проверках не участвует, `Edit(//…/**)` блок не снимает (11.08.2026). Чтение работает. Обход —
  писать через Bash (`python3 …`): bash-команды файловыми правилами не проверяются. Вывод:
  состояние headless-инструмента пишет код, ИИ-шаг отдаёт результат в stdout.
- `claude-agent-sdk` в подпроцессе учётку Claude Code не берёт — `claude-models.md`. Отдельный
  CLI не делит вход с приложением Claude — `desktop/knowledge/claude-desktop-restart.md`.

## Правила

- **Фоновые вызовы модели** из своих инструментов (имя, слаг, короткая сводка) — обычным
  `claude -p` с конфигом `~/.claude`, то есть на подписке владельца, с флагами детерминированного
  прогона выше; не заводить ради них отдельный API-ключ, другую учётку или обёртку с другим
  биллингом. Особенности учётки и сети конкретной машины — в её правилах.
