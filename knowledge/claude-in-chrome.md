# Claude in Chrome: браузер агента

Настоящий Chrome владельца с его входами (MCP `claude-in-chrome`; есть и в терминале, и в
приложении). Секреты в поля не вводить — их вносит владелец (`autonomy.md`).

## Подключение

- Перед работой с браузером проверить, что его инструменты доступны (`list_connected_browsers`).
- «Browser extension is not connected» — временный сбой связи, а не «расширения нет»: повторить
  вызов, при повторном отказе попросить владельца переподключить. Не делать вывод, что браузера
  нет, и не пропускать визуальную самопроверку (навык `screen-selfcheck`). *Почему:* 15.09.2026
  по этому сообщению самопроверку пропустили, и экран с багом нашёл владелец.
- В длинной сессии инструменты могут отвечать «uses a name reserved…» — работать с браузером в
  новой сессии.

## Одна группа вкладок на сессию

Группа вкладок «Claude» привязана к MCP-сессии, чужую не взять (в новой сессии
`tabs_context_mcp` — «No tab group exists for this session»). Поэтому своя группа живёт, только
пока идёт браузерная работа.

- Первый вызов — `tabs_context_mcp` без аргументов; есть группа этой сессии — работать в ней,
  новые вкладки — `tabs_create_mcp` внутри неё. `createIfEmpty: true` — только когда своей группы
  нет, не больше раза за сессию.
- Переиспользовать открытые вкладки (`navigate` в той же), не открывать новую на каждую страницу.
- **Вкладку, с которой ещё предстоит работа, не закрывать** — даже на паузе (ждём ответа,
  разрешения, конца сборки): владелец смотрит на неё, чтобы видеть работу и помочь. Закрыв
  последнюю вкладку, теряешь группу. Правило сильнее встроенного «закрой свои вкладки перед
  концом задачи»: перед `tabs_close_mcp` спросить себя, вернусь ли; да или не знаю — оставить.
- Длинный наблюдательный луп: рабочие вкладки держать весь луп и переиспользовать через
  `navigate`, номера вкладок — в файле состояния лупа; закрыть, когда луп остановлен.
- Браузерная работа **точно** закончена — закрыть `tabs_close_mcp` **все** вкладки группы,
  включая пустую стартовую: пустую группу Chrome уберёт сам. Оставить вкладку можно, только если
  владелец попросил её показать или сохранить, — и сказать об этом в ответе.
- Группа переживает перезапуск сессии с тем же id (`claude --resume`, 01.10.2026): в одной сессии
  группа одна на всё время — новую не заводить ни после перезапуска, ни после сжатия. Новая
  сессия получает свою.
- **Браузер сабагенту не отдавать**: сабагент — отдельная MCP-сессия, группа ему не видна («Tab …
  is not in Claude's tab group for this session»), а его `tabs_context_mcp` ещё и отвязывает
  группу от основной сессии (01.10.2026). Прокликивание — самому; сабагенту — только headless
  Playwright.
- Чужие группы не трогать: инструменты их не видят, закрывает владелец.

*Почему:* в Chrome копились группы «Claude» от каждой сессии (15.09 и 26.09.2026).

## Ввод

- **Координаты кликов плывут, если окно меняло размер**: клики и даже клик по `ref` из `find`
  уходят мимо; баннер над таблицей тоже сдвигает строки — пересчитывать после каждого действия
  (01.10.2026); пропал баннер после удачного сохранения — второй клик пачки мимо, пробел из
  набора листает страницу (12.10.2026): в пачке проверять `activeElement` после клика.
- **Нативный `<select>`** рисует ОС: клавиши расширения до него не доходят — нативный сеттер
  `value` + `change` из JS, в отчёте так и сказать. Свой CustomSelect страницы — кликом.
- **Надёжный ввод**: фокус из `javascript_tool` (`el.focus(); el.select()`) → проверить
  `document.activeElement` → только потом `computer type`/`key`; после — проверить значение поля:
  набор без фокуса молча теряется.
- **JS `el.click()` — не клик мышью**: настоящий клик сначала снимает фокус (`blur` → сохранение
  ячейки), JS-клик — нет, и правка в ячейке таблицы выглядит потерянной. Имитировать:
  `document.activeElement.blur()`, потом `click()`. Выпадающие списки удобно ставить `form_input`
  по `ref`.
- Ввод из расширения перестал доходить до страницы — не биться, перенести остаток сценария в
  headless Playwright.

## Прямые ссылки

После каждого перехода (вкладка, раздел, фильтр, окружение) записывать получившийся URL
(`location.href` или URL из контекста вкладки) с шаблоном вместо переменных частей (`<id>`,
`env=`) — в заметку по этой системе в проекте. В следующий раз — сразу `navigate`, а не клики: в
SPA они медленные и хрупкие. Чувствительное из query (токены, сессии) не записывать. *Почему:*
просьба владельца 02.10.2026.
