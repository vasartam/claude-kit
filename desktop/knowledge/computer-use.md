# Computer use (управление экраном) в приложении

## Прячет все окна не из списка

Перед каждым снимком инструмент `mcp__computer-use__*` на Windows **сворачивает (прячет) все окна
приложений, которых нет в списке разрешённых**, а не просто закрашивает их. Владелец видит, как
у него пропадают окна. *Почему записано:* 07.11.2026, снимок главного меню игры свернул владельцу
браузер, Telegram и терминал: «не надо мне сворачивать все окна».

- Нужно только **посмотреть** на окно (игра, своё приложение) — снимать своим кодом: Python
  `PIL.ImageGrab.grab()` (без аргументов — основной монитор, `all_screens=True` — все) или `mss`.
  Окно вывести вперёд через Win32: `FindWindowW(None, "<заголовок>")` → `ShowWindow(hwnd, 9)` →
  `SetForegroundWindow(hwnd)`.
- Computer use — только когда нужны клики в приложении, и тогда сказать владельцу заранее, что окна
  свернутся, или работать на мониторе, который он отдал.
- Имя приложения для `request_access` — из списка установленных; игра из Steam там обычно не
  значится, а сработало имя exe-файла процесса в нижнем регистре
  (`deadbydaylight-win64-shipping.exe`), которое инструмент сам подсказывает после первого снимка.
