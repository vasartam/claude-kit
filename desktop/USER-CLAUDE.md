# Слой desktop

Приложение Claude (вкладка Code). Знания слоя — `knowledge/` рядом с этим файлом; читать только нужный файл.

- Модель, effort, контекст, лимиты — строка хука `model-advisor` (правило — `<kit>/knowledge/model-advice.md`). Её нет — `mcp__ccd_session_mgmt__get_session` с `"self"` (поля `model`, `effort`; отложенный — сначала ToolSearch), не гадать. Свои сменить не может — переключает владелец (`claude-desktop.md`, «Effort»).
- Запасной путь — `get_usage` (окна `5-hour limit`, `Weekly · …`; `context.percentUsed`).
- Лимит тарифа общий на все сессии приложения и чат claude.ai. У 90 % — пауза по тексту хука `limit-guard`; при сессии-координаторе (навык /limit-guard) хук молчит, а её просьба о паузе — довести шаг до коммита или записанного состояния и закончить ход, ей не отвечать; «продолжай» после сброса — сначала `git status`, `git log` и свои записи.
- «Ухожу спать», «работай без меня», «оставляю компьютер включённым» — навык /night-work.
- Будильники `CronCreate` стирает перезапуск приложения или компьютера; рутины переживают, но писать в сессии не могут — `claude-desktop-restart.md`.
- Окружение вкладки Code отличается от терминала (`ANTHROPIC_BASE_URL`, `NO_PROXY`, PATH) — `claude-desktop.md`.

## Сжатие и закрытие сессии

- **Сжать** — после раскладки отдельной командой Bash `echo "context-compact -- <инструкция ≤250 символов>"` (в двойных кавычках, внутри без `"`, `$`, `` ` ``): мод `context-compact` сожмёт после хода и пришлёт продолжение; что именно писать, говорит хук context-guard. Без мода сжимает только владелец (`/compact <инструкция>`).
- **Закрыть** — сначала слово прощания (`answer-style.md`) (после закрытия ответить нельзя), в том же ответе — `mcp__ccd_session_mgmt__archive_session` с `session_id: "self"` и причиной «конец сессии». Архив обратим (список «Archived»). Приложение может попросить подтвердить; откажет при живой фоновой работе — сказать владельцу, что мешает. Инструмента нет — попросить владельца закрыть сессию самому.
