# Ночная работа

Лимит тарифа **общий на все сессии**. Цель: ни одна сессия не умирает молча на лимите — все
ждут сброса и продолжают; утром у владельца честные отчёты. Опыт ночи 26.09.2026 (личный проект):
лимит дошёл до 96 %, работа встала на паузу и продолжилась после сброса.

Инструменты — `mcp__ccd_session_mgmt__*` (отложенные — сначала ToolSearch) и `CronCreate`.

## Роли и реестр

- **Координатор** — один. Любая сессия, получившая указание о ночной работе, сначала ищет в
  `~/.claude/night-work/` папку, изменённую меньше 12 часов назад: есть — она **исполнитель**
  этой ночи и регистрируется там; нет — она координатор и создаёт папку `<ГГГГ-ММ-ДД>` (дата
  начала вечера; после полуночи — вчерашняя) с `README.md`, где записан её `sessionId`. Так же
  попадает в реестр сессия, заведённая владельцем среди ночи.
- **Исполнитель** — каждая сессия с ночной задачей. При двух и более исполнителях
  координатору своей задачи лучше не брать; если берёт — шагами до ~30 минут (его проверки
  срабатывают только между его ходами).
- Файл исполнителя `<sessionId>.md`: задача, репозиторий, `permissionMode`, effort, статус, id и
  минута страховочного будильника, путь к черновику отчёта, раздел **«Ждёт владельца»** и
  **«Журнал»** — на каждой контрольной точке строка `ЧЧ:ММ | 5ч N % / неделя M % | что
  сделано или «пауза до ЧЧ:ММ»`.
- Статусы: `working`; `paused` (ждёт сброса лимита); `blocked` — **только** когда без
  владельца делать больше нечего; `done`.

**Координатор:** старт, ежечасная проверка и утренняя сводка —
[references/coordinator.md](references/coordinator.md), прочитать целиком; паузы и пробуждение
после сброса — по навыку **limit-guard** (загрузить и его). Исполнители следят за лимитом сами.

## Цикл исполнителя

**Сразу:** `get_session self` → `sessionId`, `permissionMode`; файл реестра; **черновик
отчёта** по шаблону навыка morning-newspaper (`references/report-template.md`) — дописывать
после каждой задачи и перед каждой паузой (утром отчёт есть, даже если лимит кончился).
Работа — шагами, каждый шаг кончается коммитом (push — как принято в проекте) и строкой журнала.

**Страховочный будильник — ровно один, повторяющийся.** `CronList`: свой night-work уже есть —
не ставить второй. Нет — `CronCreate` recurring `"<M> * * * *"`, где `M` — минута сброса
5-часового окна + 5 (не 0 и не 30 — сдвинуть на 1), промпт самодостаточный: «Продолжение
ночной работы по навыку night-work. Реестр: <путь к своему файлу>». Id и минуту — в реестр.
Одноразовый не годится: он удаляется при срабатывании, и если этот ход отклонён лимитом,
цепочка рвётся до утра. Срабатывает только в свободной сессии.

**Любое «продолжай» (будильник, координатор, повтор) — идемпотентно.** Первое действие:
свой файл реестра и `get_usage`. `done`/`blocked` → одна строка, конец хода. Лимит ≥ 90 % → конец
хода (будильник стоит). Пришло посреди работы — продолжать текущий шаг, не начинать заново;
шаг сделан, только если его коммит есть в `git log`.

**Контрольная точка** — после каждого шага и не реже раза в ~30 минут: `get_usage`. Окна по
`label`: `5-hour limit`; недельное — большее из `Weekly · all models` и недельного окна своей
модели.

| Состояние | Что делать |
|---|---|
| 5 ч < 85 % | работать |
| 5 ч 85–90 % | ничего дорогого (workflow, панели агентов, большие сборки); доводить мелкое |
| 5 ч ≥ 90 % | **пауза:** коммит, черновик отчёта, реестр `paused` + «пауза до ЧЧ:ММ», конец хода |
| неделя ≥ 90 % | отчёт сейчас, `done` с пометкой «встал на недельном лимите», снять будильник |
| `status: unavailable` | повторить через минуту; снова нет — мелкими шагами, проверка через 15 минут |

**Экономия общего лимита:** без многоагентных панелей и повторных перепроверок ночью, один
агент вместо трёх; дорогое — сразу после сброса.

**Чего не делать ночью:** решения за владельца, секреты, оплата, необратимое и наружное сверх
разрешённого, чужие службы на общих серверах. Всё такое — в «Ждёт владельца»; статус остаётся
`working`, пока есть другая работа. Свою задачу закончил рано — новой вне неё не придумывать:
проверки и документация по ней, отчёт, `done`.

**Минута будильника:** `resetsAt` — UTC, cron — местное время; перевод — `references/wake.md`
навыка limit-guard (+ 5 минут вместо + 4). Нет `resetsAt` — `M` из прошлого сброса.

## Утро и отчёты

Утро (по умолчанию 09:00) — время отчёта, а не остановки. Отчёт, утренняя газета и сводка —
[references/morning.md](references/morning.md).
