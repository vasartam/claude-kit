# Утро и отчёты ночной работы

Часть навыка night-work: что делать к утру. Роли, реестр и цикл исполнителя — в SKILL.md.

- **Утро** (время, названное владельцем; по умолчанию 09:00) — время отчёта, а не остановки:
  отчёт по состоянию на утро пишется; работа осталась и владелец её не остановил — продолжать
  по тем же правилам и дописать отчёт в конце.
- **Исполнитель:** отчёт из черновика в `docs/reports/<ГГГГ-ММ-ДД>-night.md` репозитория (две
  сессии в одном репозитории — `…-night-<тема>.md`; перед push — `git pull --rebase`); нет
  репозитория — рядом с файлом реестра. Шаблон и правила отчёта — навык morning-newspaper
  (`references/report-template.md`). Реестр `done` + путь; `CronDelete` будильника; в чат —
  выжимка со ссылкой.
- **Утренняя газета — обязательно, сама, без напоминаний:** сверстанная страница-Artifact по
  отчёту — навык morning-newspaper. Ссылка — в чат и в файл реестра.
- **Координатор** — утренняя сводка по [coordinator.md](coordinator.md) и общая газета по всем
  сессиям (главная страница утра со ссылками на газеты сессий).
- Отчёт честный: что проверено живьём / только тестами / не проверено; свои ошибки — первыми
  в «Происшествиях».
