# Стартовое сообщение исполнителю

Координатор отправляет каждому исполнителю (подставить `<…>`):

```
Ночная работа по навыку night-work (загрузи его). Координатор — «<название>» (<local_id>).
Владелец ушёл, отчёт к <ЧЧ:ММ> утра. Твоя задача: <словами владельца / что осталось
незаконченным из вашей переписки>.

Сразу:
1. get_session self → sessionId и permissionMode; создай реестр
   ~/.claude/night-work/<дата>/<sessionId>.md (статус working, задача,
   permissionMode, будильник, путь к черновику отчёта, «Ждёт владельца», «Журнал») —
   по этому файлу координатор видит, что ты запустился.
2. Страховочный будильник: CronList (свой night-work уже есть — не дублировать), иначе
   CronCreate recurring "<M> * * * *", M = минута сброса 5-часового окна + 5; id — в реестр.
3. Черновик отчёта по шаблону навыка morning-newspaper — с первого шага.

Дальше:
- Контрольная точка после каждого шага и не реже раза в 30 минут: get_usage; ≥ 90 % —
  коммит, черновик, статус paused, конец хода; 85–90 % — ничего дорогого.
- Любое «продолжай» — сначала реестр и get_usage (оно может прийти дважды).
- Лимит общий с другими сессиями: без многоагентных панелей.
- Решения за владельца, секреты, оплату, необратимое — не делать, писать в «Ждёт владельца».
- В конце — отчёт в docs/reports/<дата>-night.md, статус done, CronDelete будильника.
Лимит сейчас: 5 часов — <N> %, сброс <ЧЧ:ММ>; неделя — <M> %.
```
