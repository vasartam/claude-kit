# Сообщения координатора лимита: кому писать и тексты

Подставить `<…>`. Всегда заканчивать «Отвечать мне не нужно» — ответ тоже тратит лимит.

## Кому и как писать

- Остановленным не писать — сообщение запустит у них ход и потратит тот же лимит. Сессии
  планировщика сообщений не принимают. Исполнители night-work следят за лимитом сами — им не
  писать, но будить после сброса можно. При ≥ 90 % не слать сообщений совсем: запас уже съеден,
  каждое сообщение — ход.
- Субагенты и фоновые задачи чужой сессии координатору не видны (`TaskStop` — только в своей).
  Субагенты тратят тот же лимит; фоновая команда не тратит, но её завершение будит сессию новым
  ходом. Поэтому просьба о паузе просит саму сессию остановить лишнее. Видно косвенно:
  `isRunning` и `<task-notification>` в `list_events`.
- `send_message`: `delivered` — сессия взяла сообщение сразу; `queued` — дойдёт после её
  текущего хода (она ещё потратит немного).
- Жёстко (`stop_session`) — только по просьбе владельца. Окно ≥ 97 %, а сессия после просьбы
  всё ещё идёт — сказать владельцу и предложить остановить.

## Предупреждение (5 ч 85–90 %)

```
Пятичасовой лимит тарифа уже <N> %, сброс в <ЧЧ:ММ> МСК. Дорогого сейчас не начинай
(многоагентные панели, большие сборки, широкие исследования) — доводи текущее. Отвечать мне
не нужно.
```

## Просьба о паузе (5 ч ≥ 90 %)

```
Пятичасовой лимит тарифа уже <N> %, сброс в <ЧЧ:ММ> МСК. Работу не бросай: доведи текущий шаг
до удобной точки (коммит или записанное состояние — что сделано и что дальше) и на этом
закончи ход. Субагентов не запускай; работающих — дождись или останови. Фоновые задачи
(команды, мониторы, серверы), которые больше не нужны, — останови (TaskStop); нужные — запиши
в заметку, что идёт и зачем. Если задача уже закончена — просто так и скажи. В <ЧЧ:ММ+4> я (сессия-координатор
«<название>») напомню продолжить с этого места. Если лимит оборвёт ход раньше — тоже не
страшно, продолжишь после сброса. Отвечать мне не нужно.
```

## Продолжай (после сброса)

```
Лимит тарифа сброшен (<ЧЧ:ММ> МСК). Твоя работа встала на паузу / оборвалась на лимите —
продолжай с того места, где остановился. Сначала сверь git status / git log и свои записи,
не повторяй уже сделанное.
```

## Недельное окно

Предупреждение (85–90 %) и просьба о паузе (≥ 90 %) — те же тексты, но «недельный лимит тарифа»
и сброс с датой: «сброс <ДД.ММ ЧЧ:ММ> МСК». В паузе добавить: «остаток недели оставляем
владельцу на его задачи; продолжишь после недельного сброса — я напомню».
